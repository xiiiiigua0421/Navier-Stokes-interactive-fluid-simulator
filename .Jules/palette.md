## 2024-05-24 - Context-Aware Cursors in Interactive Pygame Views
**Learning:** In Pygame applications with split views (e.g., an interactive canvas next to a static side panel), it is critical to provide contextual cursor feedback. Users need visual cues to distinguish between "interactive/drawable" areas and "read-only/control" areas. Changing the cursor dynamically based on coordinates provides this immediate feedback.
**Action:** When implementing split-view or multi-context interfaces in Pygame, use `pygame.mouse.set_cursor()` within the `MOUSEMOTION` event handler to change the cursor (e.g., to a crosshair for drawing, arrow for panels) based on the mouse position. Remember to wrap the call in a `try/except pygame.error` block to prevent crashes in headless testing environments.
