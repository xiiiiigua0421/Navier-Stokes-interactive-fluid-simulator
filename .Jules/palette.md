## 2023-11-20 - Context-Aware Cursors in Game UIs
**Learning:** For game-like interfaces with distinct interactive zones (like a simulation area vs. a UI panel), using a single cursor can make interactions feel disconnected. A context-aware cursor provides immediate affordance (e.g. crosshair for drawing/targeting vs arrow for standard UI selection).
**Action:** When working on mixed interactive UIs (canvas + control panels), always consider dynamic cursor updates based on hover zones to reinforce different interaction paradigms.
