## 2024-05-24 - Crosshair Cursor for Interactive Simulation Canvases
**Learning:** In fixed-window applications containing both a dense interactive canvas (like a fluid simulation) and static UI panels, users often struggle to intuitively differentiate draggable zones from non-interactive information areas when the default arrow cursor is used everywhere.
**Action:** Dynamically change the cursor to a crosshair when hovering over the interactive simulation zone, and revert to an arrow over static panels, clearly communicating affordances.
