## 2024-10-24 - Visual state indication for pause

**Learning:** When interacting with real-time simulations, users need unambiguous visual feedback when global state changes (like pausing). A small text change in a side panel is insufficient because user attention is often focused on the main view.
**Action:** Always provide explicit, centered or full-view overlays (like a semi-transparent screen with an icon) for critical interactive state changes (like pausing/playing) in simulations or complex visual applications.
