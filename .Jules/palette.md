## 2024-05-24 - Context-Aware Mouse Cursors for Interactive Canvas
**Learning:** In canvas-based applications where only a specific region is interactive (like a fluid simulation view vs. a control panel), users lack visual affordance that dragging/clicking is possible.
**Action:** Implemented dynamic mouse cursor changes (e.g., crosshair over simulation, arrow over panels) based on cursor position to clearly distinguish interactive zones from static/control zones.
